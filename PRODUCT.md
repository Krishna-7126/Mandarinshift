# Product

<!-- impeccable:product-schema 1 -->

## Platform

Windows desktop application

## Users

Students, office professionals, developers, and everyday Windows users who
frequently convert images, PDFs, documents, and other files locally. They want
a fast, reliable, privacy-first tool without uploading files or navigating
complicated workflows.

## Product Purpose

LocalShift helps Windows users convert files and complete common PDF tasks on
their own device. Success means users can add one or more files, choose a
supported output format and destination, convert locally, and clearly verify
the result within their first minute.

## Positioning

LocalShift processes files locally rather than requiring uploads to a
conversion service. It is intended to be fast, reliable, private, and
predictable for common file conversion and PDF workflows.

## Operating Context

- Users commonly convert one file or a small batch, selecting a supported
  output format and destination.
- Some users also use the searchable PDF productivity suite and PDF workbench.
- The application runs as a Windows desktop utility and supports file browsing
  and drag-and-drop workflows.
- The optional global Shift+Drag gesture is explicitly opt-in; physical
  compatibility with external drag sources is not certified.

## Capabilities and Constraints

- File conversion and PDF operations run locally; no upload is required.
- Preserve existing supported conversion routes and PDF workflows.
- Conversion must not modify the original source files.
- Global gesture monitoring remains off by default and requires explicit
  consent.
- User success depends on clear supported-format choices, destination
  selection, progress/results, and actionable failure states.

## Brand Commitments

- Preserve the LocalShift name.
- Privacy-first local processing is a core product promise.
- Avoid making universal external drag-source compatibility claims without
  physical verification.
